# Подсчет людей на видео с YOLO/RT-DETR

Приложение для подсчета количества людей на видео и анализа потока людей с использованием моделей YOLOv8/RT-DETR.

## Возможности

- Детекция людей на видео в реальном времени
- Трекинг объектов между кадрами
- Подсчет входа/выхода через виртуальную линию
- Визуализация результатов с аннотациями
- Статистика потока людей
- Экспорт результатов в CSV и графики

## Установка

```bash
pip install -r requirements.txt
```

## Использование

### Базовый запуск

```bash
python people_counter.py --video input.mp4 --output output.mp4
```

### С параметрами

```bash
python people_counter.py \
  --video input.mp4 \
  --output output.mp4 \
  --stats stats.csv \
  --model yolov8n.pt \
  --line_ratio 0.5 \
  --conf 0.4
```

### Параметры

- `--video` - путь к входному видео (обязательно)
- `--output` - путь к выходному видео с аннотациями
- `--stats` - файл для сохранения статистики (CSV)
- `--model` - модель YOLO (yolov8n.pt, yolov8s.pt, rt-detr-l, etc.)
- `--line_ratio` - положение линии подсчета (0.0-1.0, по умолчанию 0.5)
- `--conf` - порог уверенности детекции (0.0-1.0)

### Визуализация статистики

```bash
python visualizer.py --stats stats.csv --output plots
```

## Алгоритм работы

1. Загрузка видео и инициализация модели YOLO
2. Детекция людей на каждом кадре
3. Трекинг объектов по ближайшему соседу
4. Проверка пересечения виртуальной линии
5. Подсчет входа/выхода
6. Сохранение результатов и визуализация

## Требования

- Python 3.8+
- CUDA (опционально, для ускорения)
- Минимум 4GB RAM

## Примеры моделей

- `yolov8n.pt` - быстрая, легкая модель
- `yolov8s.pt` - баланс скорости/точности
- `yolov8m.pt` - высокая точность
- `rt-detr-l.pt` - RT-DETR модель

## Вывод

Приложение создает:
- Видео с аннотациями (`output.mp4`)
- CSV файл со статистикой (`stats.csv`)
- Графики в папке `plots/`
- Текстовый отчет со сводкой
